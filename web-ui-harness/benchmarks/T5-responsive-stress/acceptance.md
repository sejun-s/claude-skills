# T5 acceptance

## 기능
- 내비게이션 9개 링크 + CTA가 **모든 폭에서 접근 가능**(숨기면 대체 수단 제공: 메뉴 버튼 등).
- 요금제 표: 4플랜 × 8행의 모든 값이 모든 폭에서 **읽을 수 있고 비교 가능**(가로 스크롤, 카드 재구성, 고정 열 등 방식은 자유). 표 때문에 **페이지 전체**가 가로 스크롤되면 결함.
- 기능 카드 8개: 제목 길이 차이로 레이아웃이 깨지지 않음.
- 폼: 필드 8개, 라벨 연결, 모든 입력의 터치 타깃 ≥ 24px, 체크박스 라벨 클릭 가능.

## Mechanical 기준 (핵심 task)
- 320–1440 스윕 전 구간(64px 간격 + 375/768/1024)에서 horizontal-overflow 0(표의 **내부** 스크롤 컨테이너는 허용), clipped-text 0, touch-target<24px 0.
- 가로 스윕 결과는 `report.json`의 폭별 결함 개수로 비교한다. 추가로 스윕에서 결함이 발생한 폭 앞뒤를 보강 캡처한다.
