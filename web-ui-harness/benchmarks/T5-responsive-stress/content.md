## 기능 카드 (8개, 제목 길이가 서로 다름)
1. 업무 보드 — 칸반과 타임라인을 한 화면에서 전환합니다.
2. 자동화 규칙 — 조건에 따라 담당자 지정과 상태 변경을 자동으로 처리합니다.
3. 승인 요청 — 검토가 필요한 항목을 지정된 순서에 따라 승인자에게 전달합니다.
4. 외부 서비스 연동을 통한 알림 통합 관리 — 메신저, 이메일, 캘린더의 알림을 한곳에서 확인합니다.
5. 리포트 — 팀별 처리 속도와 지연 항목을 주간 단위로 요약합니다.
6. 템플릿 — 반복되는 업무 구조를 저장해 새 프로젝트에 바로 적용합니다.
7. 권한 관리 — 프로젝트와 항목 단위로 열람·편집 권한을 구분합니다.
8. 감사 로그 및 변경 이력 추적 — 누가 언제 무엇을 바꿨는지 기록으로 남깁니다.
