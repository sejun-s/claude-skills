# 04 디자인 계약 (구현 전에 정하고, 6단계에서 대조한다)

- 초점(첫 화면에서 가장 먼저 읽힐 것):
- CTA 위계: 주 1개 / 보조는 시각적으로 더 약함
- 시그니처(이 사이트의 개성 1개. 여러 개 금지): 
- 타입 스케일 (역할별 크기). **본문·라벨 최소 크기 12px, 절대 하한 11px.**
- 색 역할 (배경/글자/액션/상태). 상태는 색만으로 표시하지 않는다.
- 시각물 계획: 각 시각물이 **무엇을 설명하는가**. 설명 못 하면 쓰지 않는다. 에셋 출처·라이선스:
- 모션: 쓴다면 목적 1줄 (드러냄/설명/유도). 없으면 "없음".
- 반응형: 모바일에서 순서·구조가 어떻게 바뀌는가 (축소가 아니라 재구성).
- 한국어: `lang="ko"`, 로컬 폰트(로드 확인), 본문 `keep-all` 후보, 좁은 표·긴 단어 overflow 확인.
