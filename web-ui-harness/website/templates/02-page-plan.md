# 02 페이지 기획

## 사이트 구조
| 페이지/섹션 | 방문자 질문 | 이 섹션의 역할 (메시지 / 증거 / 행동 중 무엇) | 사용할 콘텐츠 (의뢰서 출처) | 표현 수단 (텍스트·제품 UI·다이어그램·숫자·비교…) |
|---|---|---|---|---|

- 내비게이션 항목마다 **대응하는 콘텐츠**가 있는가? (없으면 항목을 빼거나 `FAKE/TODO`로 표시)
- 같은 구조(카드 3개 등)를 반복하는 섹션이 있으면 **반복해도 되는 이유**를 쓴다.

## 첫 화면 계약 (스크롤 없이 보이는 영역, 데스크톱·모바일 모두)
- [ ] 무엇을 하는 서비스인가: (문구)
- [ ] 누구를 위한 것인가: (문구) ← 직접 쓴다, 추론에 맡기지 않는다
- [ ] 주 행동: (버튼 문구) — 보조 행동은 더 약하게
- [ ] 믿을 근거 1개 이상 (수치·사례·제품 화면 중, 의뢰서의 실제 자료만): 
- 근거가 없으면 비워 두고 `증거 없음`을 사용자에게 알린다. 근거를 만들어내지 않는다.

## 카피 규칙
- 의뢰서에 없는 수치·고객·성과 문구를 만들지 않는다.
- 약속·기한("1영업일 내 연락" 등)은 사용자 승인 없이 쓰지 않는다.
- 가상 데이터는 화면에 표시하고, 없는 기능(전송·저장·인증)을 성공한 것처럼 보이지 않는다.
