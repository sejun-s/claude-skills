# 05 백엔드 인계

| 화면 요소 | 현재 상태 (실제 / FAKE / 미구현) | 필요한 백엔드 | 입력 → 출력 (초안) | 검증·오류 처리 |
|---|---|---|---|---|
| 예: 문의 폼 | FAKE (전송 없음, 화면에서만 처리) | POST /api/inquiries | name, email, message → 201 + id | 필수·이메일 형식, 중복·스팸 방지 |
| 예: 설비 목록/차트 | FAKE (고정 데이터) | GET /api/machines, /api/machines/:id/risk | — → 목록/시계열 | 기간 파라미터, 빈 상태 |

- 화면의 가짜 성공(전송했다고 보이는 문구 등)은 **연결 전에 제거하거나 연결 후 의미가 맞게 교체**한다.
- 개인정보 수집·보관 문구는 법무 검토 대상으로 표시한다.
