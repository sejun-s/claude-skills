# 03 레퍼런스 노트 (선택)

참고 사이트마다 아래 세 칸을 **섞지 않고** 적는다.

| 사이트 | 관찰 (값·사실) | 추론 (왜 그렇게 했을까, 확신도, 반대 가설) | 가져올 원칙 (이 프로젝트에 맞게) |
|---|---|---|---|
| | 예: 헤드라인 64px, 제품 화면이 첫 화면 절반 | 예: 메시지 우세를 위해 큰 대비를 쓴 것 (0.7). 짧은 카피 보완일 수도 | 예: 초점은 하나, 나머지는 낮춘다 |

- 값 추출은 `dembrandt` 등 기존 도구를 쓴다. **복제하지 않는다.**
- 추론은 사용자 확인 없이 규칙으로 승격하지 않는다.
- 사용자가 싫어한 것은 "나쁜 디자인"이 아니라 "이 목적과 맞지 않음"으로 적는다.
