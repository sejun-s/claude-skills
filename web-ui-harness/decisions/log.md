## D-002 — T1 패널·T3 결과 이후 (2026-10-02)
- brief v0.2의 문구 추가 금지 문장은 효과가 있었다(6/6 → 0/6). T1 결과는 카피 교란이 있는 것으로 읽고, 카피 교란이 없는 T3·T5를 기준으로 삼는다.
- **우리 Harness의 비교 대상은 A(Plain Claude)가 아니라 B(기존 스킬 스택)이다.** T1 패널에서 B가 A보다 일관되게 상위였으므로, 새 기능은 B가 못 푸는 것에서만 정당화된다.
- 승격 후보: F-009(한국어 제목 구 단위 줄바꿈, T1·T3 반복). 보류: 첫 화면 신뢰 증거·대상 명시(T1 한 task).
- 다음: T5 baseline(반응형, 카피 교란 없음)을 실행해 승격 기준(≥2 task)을 재점검한 뒤 STEP 7 착수.
- 정정 기록: T3 스크린샷의 run 대응을 잘못한 서술을 철회함(failures/log.md). 병렬로 읽은 이미지의 대응이 보장되지 않으므로, 이후 run별 시각 판단은 단일 이미지 읽기 또는 파일명이 박힌 캡처로 한다.

## D-003 — ko-heading-wrap 판정 (2026-10-02)
클로드 스킬 전문가 관점: 새 스킬이 아니라 기존 스택에 덧붙이는 얇은 확장 + 결정론적 측정 스크립트로 구현. 승격 기준(≥2 task, 기존 도구가 못 풂)을 만족한 F-009만 대상으로 ablation(A / B / C-leaky / C-clean) 수행.
- 결과: C-clean이 B 대비 구 쪼개짐 10 → 1. leaky와 clean이 같아 오염 영향은 아님으로 판단.
- 결정: **유지**, SKILL.md를 v0.2로 개정(좁은 폭 해제 금지, 묶음 길이 제한). v0.2는 미검증 상태로 표시.
- 교훈: (1) 스킬/지침 안의 예시에 평가 대상 문구를 넣으면 평가가 오염된다 — 예시는 benchmark와 분리. (2) 에이전트의 "확인했다/0건" 보고는 독립 측정으로 검증한다. (3) 측정 스크립트를 스킬에 넣으면 에이전트가 자기 오류를 스스로 잡는 효과가 있다(5/6 run).

## D-004 — 자율 세션 계획 (UI 디자이너 × 클로드 스킬 전문가 논의, 2026-10-02)
논의 입력: 두 역할을 맡은 에이전트의 의견(`experiments/eval/discussion/*.md`, 같은 모델 계열이라 독립 전문가가 아님). 사용자는 식사 중이며 "의사결정은 그냥 하세요"로 위임.

일치: T5 baseline 실행, v0.2 재측정, 사용자 blind 패키지 준비. 금지: 수치 규칙 사전 확정, 임의 임계값 리듬 검사기, 같은 모델 proxy 순위의 개선 근거 인용, 이미지 병렬 읽기로 run별 결론, 실험 중 도구 수정.
쟁점: 디자이너는 "첫 화면 신뢰 증거·대상 명시"가 영향 1순위이나 근거 부족(T1 한 task, 카피 교란) → **승격하지 않고 후보로만 유지**, 후보 검증(T1 v0.3: 실제처럼 보이는 가상 값 + 짧은 결정 규칙)은 다음 단계로 미룸.
스킬 전문가 지적 약점 수용: (1) 스킬 지식 효과와 스크립트 루프 효과가 섞임 → **위약 대조군 D = B + 스크립트만** 추가. (2) gold가 자명한 구 위주·작성자=Claude → **hold-out T3b(어려운 구)로 재검증**, gold 비공개. (3) 스크립트가 `--keep` 목록만 검사하는 순환 → v0.2에서 `--keep` 없이도 모든 제목 줄 구성·고아·넘침을 출력하고 "구 쪼개짐 미검사"를 명시. (4) 실험 중 도구 변경 금지 → 버전 고정(`VERSION`, `CHANGELOG`, git tag `ko-heading-wrap-v0.2.0`).

실행 계획: T5 {A, B, C} ×3 + T3b {B, D, C} ×3. C = B + ko-heading-wrap v0.2.
성공 기준(사전 고정): T3b에서 C의 gold 구 쪼개짐이 B와 D보다 적고 부작용(넘침·문구 추가) 없음 → 스킬 지식 효과로 인정. C ≈ D이면 → 스크립트(측정 유틸)만 유지하고 SKILL.md는 단순화/삭제. C ≥ B이면 삭제 검토.
정직한 종료 문구: "기능 1개가 기술적으로 검증됨, 디자인 품질 판정은 사용자 blind 평가 대기."

## D-006 — ko-heading-wrap 판정 수정 (hold-out 결과, 2026-10-02)
- T3b hold-out(어려운 gold, 위약 D 포함)에서 C가 B·D 대비 일관된 개선을 보이지 않음(합 12 vs 16·15, run 편차 0~7, 넘침 1건). 사전 기준 **미충족**.
- 결정: **"효과 입증됨"을 철회한다.** SKILL.md를 *experimental* 로 격하(헤더에 상태 명시), `heading-lines.mjs`는 **측정 유틸**로 유지. Harness v0.1의 "승격 기능"은 현재 **0개**이며 ko-heading-wrap은 후보 상태다.
- 판정은 사용자 blind 제목 비교(`experiments/eval/human-blind-headings`)로 확정한다: 사람이 C 제목을 더 자연스럽다고 일관되게 고르면 유지, 아니면 SKILL.md 삭제하고 유틸만 남긴다.
- 한계 정직 표기: 효과는 gold(저자=Claude)·에이전트의 구 선택에 크게 의존하고, 표본은 조건당 3회다.
