# QA 체크리스트 (Claude QA 담당, ChatGPT 산출물 검수용)

각 항목에 PASS / FAIL / 확인불가 + 근거(파일·명령)를 적는다. 한 항목이라도 FAIL이면 해당 결론은 반려한다.

## 재현성
- [ ] 보고된 수치를 **원 데이터에서 직접 재측정**했을 때 일치하는가(환경 차이는 명시). 측정은 폰트 로드 확인 상태인가(exit 3 아님)?
- [ ] 사용한 도구·gold·brief·SKILL 버전이 **실험 전에 고정**(커밋 SHA 기록)되었고 실험 도중 바뀌지 않았는가?
- [ ] 새 결과가 기존 결과 파일을 **덮어쓰지 않았는가**(git diff로 `runs/`·기존 로그 본문 삭제/수정 여부 확인)?
- [ ] run마다 조건 프롬프트·모델·브라우저·폰트 해시가 기록되었는가?

## 타당성
- [ ] **gold/키 누출 없음**: 생성 프롬프트·SKILL·예시·스크립트 주석에 gold 문구나 평가 키가 들어갔는가(grep)?
- [ ] 위약 대조군(D)과 hold-out이 포함되었는가? 지침 효과와 측정 루프 효과가 분리되었는가?
- [ ] 비교 조건 간 **교란**(문구 추가, 프롬프트 차이, 모델 차이, 레이아웃 차이)을 명시했는가?
- [ ] 사후 분류(결과를 본 뒤 만든 tier·기준)를 **탐색적**으로 표기했는가?

## 주장 대 데이터
- [ ] "효과 입증/개선/승격" 표현이 표본 크기·분산·평가자 독립성에 비해 과하지 않은가? 같은 모델 계열 평가를 최종 근거로 쓰지 않았는가?
- [ ] 단일 task·3회 결과를 일반화하지 않았는가? "0건"이 측정기 미탐일 가능성을 적었는가?
- [ ] 에이전트/모델 자기 보고를 실측 없이 사실로 인용하지 않았는가?
- [ ] 정정·철회가 로그에 **눈에 띄게** 남았는가?

## 도구·평가 패키지
- [ ] 회귀 테스트(`skills/ko-heading-wrap/tests/run.sh`)가 통과하고, 의도적으로 결함을 넣으면 실패하는가(negative control)?
- [ ] blind 패키지: 좌우·순서 무작위, 파일명/HTML/메타에 조건 누출 없음, 패키지별 저장 키, export에 pack/seed/format 포함, 키 파일 분리?
- [ ] 이미지가 **Pretendard로 렌더**되었는가(폰트 미로드 crop 없음)?

## 형식
- [ ] README의 상태 표(승격/후보/기각)가 실제 증거와 일치하는가? 승격 0개라면 그렇게 쓰였는가?
- [ ] 커밋이 작고 설명적인가, 대용량 불필요 파일(폰트 등)이 없는가?
