# 알파로그 랜딩 시안 S1~S6 평가 (웹 기획자 관점)

## 1) 5초 테스트 (firstfold-desktop.png만 보고)
공통: 6개 모두 첫 화면에 "설비 로그에서 고장의 징후를 먼저 찾아냅니다" + 설명문 + [데모 신청하기]/[도입 사례 보기] + 위험도 대시보드 목업이 있어 Q1~Q3 답이 거의 같다. 차이는 Q4와 시각 요소.

| 시안 | Q1 무엇 | Q2 누구 | Q3 다음 행동 | Q4 신뢰 근거 |
|---|---|---|---|---|
| S1 | 설비 로그 분석 예지 정비 SW | 공장 설비 관리자(명시 문구 없음, 추론) | 파란 '데모 신청하기' 클릭 | 첫 화면에 구체 증거 없음. 대시보드 목업(사출기 07, 원인 후보 3개)만 있어 제품 실재감 정도 |
| S2 | 동일 | 공장 설비 담당(추론) | '데모 신청하기' | 증거 없음. 하단에 어두운 섹션이 시작될 뿐 내용 확인 불가 |
| S3 | 동일 | 동일 | '데모 신청하기' | 증거 없음. 목업 캡션 "설비별 위험도와 추이를 한 화면에서 확인"과 아래 회색 설비 일러스트(실사 아님)만 보임 |
| S4 | 동일. "예지 정비 소프트웨어" 카테고리 라벨이 헤드라인 위에 있어 가장 빠름 | 동일 | '데모 신청하기' | 증거 없음 |
| S5 | 동일 | 동일 | '데모 신청하기' | 증거 없음. 하단 여백만 보임 |
| S6 | 동일(카테고리 라벨 있음) | 동일 | '데모 신청하기' | 증거 없음 |

결론: 첫 화면만으로는 6개 모두 신뢰 증거(수치·고객·인증)가 0개. 5초 테스트에서 Q2(누구를 위한가)도 명시 문구가 없다.

## 2) 순위 (전체 페이지 + 모바일 확인 후)
공통 확인 사실: 수치 38%(12개 공장, 6개월 평균)/4.2일/3주, 고객 인용 1건(김지훈, 가상정밀 생산기술팀 팀장), 3대 기능, 4단계 도입. 고객사 로고, 보안/인증, 가격 정보, 실제 사례 상세 페이지 내용은 어느 시안에서도 확인 불가. 모든 시안이 상단 메뉴에 '가격'(S2만 '가격 문의')이 있으나 가격 정보 섹션은 없음. '도입 사례 보기' CTA의 도착 지점은 확인 불가.

### 1위 S2
- 장점: 수치를 두 번째 섹션에 올리고 "정지가 일어나기 평균 4.2일 전에 알려드립니다"라는 결과형 헤드라인으로 바꿔, 구매 담당자가 가장 궁금한 효과가 스크롤 한 번 안에 나온다. 폼은 마지막에 인라인(이름·회사명·업무용 이메일·연락처·관심 설비)이고 "영업일 1일 이내 연락"이라는 응답 기대치를 명시. 인용 옆 "우리 공장에 맞는 도입 방식 상담하기" 링크로 중간 전환 경로도 있음.
- 결함: 4.2일 타임라인 시각화가 점 하나와 라벨 두 개뿐이라 정보량이 적고 공간만 크게 차지. 설비 일러스트는 회색 박스 플레이스홀더 느낌.

### 2위 S3
- 장점: 히어로 바로 아래에 3개 수치 띠를 배치해 신뢰 증거가 가장 빨리 나온다(전체 시안 중 가장 이름). 폼 옆에 "설비 로그는 읽기 전용으로만 연결합니다" 등 구매 담당자의 보안 불안을 겨냥한 안심 문구가 있다.
- 결함: 폼 하단에 "제출하면 메일 앱이 열립니다"라고 되어 있어 mailto 방식 제출로 보임. B2B 리드 수집 흐름으로는 이탈 위험이 큼. 모바일 헤더는 '메뉴' 버튼만 있고 헤더 CTA가 없음(히어로 CTA는 있음).

### 3위 S5
- 장점: 38%를 크게 키우고 4.2일·3주를 보조 수치 표로 정리해 인용과 한 줄에 놓아 증거 블록이 한눈에 읽힌다. 파란 전환 밴드의 폼은 마지막 CTA임이 분명하고 필드가 짧다(이름·회사명·이메일·주요 설비 예시 입력).
- 결함: 기능 섹션이 텍스트 목록뿐이고 그 뒤에 설명 없는 설비 일러스트 대형 밴드가 들어가 스크롤만 늘림. 수치가 페이지 후반(4번째 섹션)에 있어 신뢰 증거가 늦음.

### 4위 S4
- 장점: 섹션 라벨(핵심 기능/도입 흐름/도입 성과/데모 신청)이 있고 "멈추기 전에 알고, 영향이 적은 때에 점검합니다"라는 혜택형 문장이 명확하며, 폼 옆 체크리스트(읽기 전용 연결·2주 검증·3주 시작)와 "도입 조건, 가격 안내" 문구가 구매 불안을 줄인다.
- 결함: 도입 단계가 가로 칩 다이어그램과 4개 카드로 같은 내용을 중복 표시해 길이만 늘고, 수치(신뢰 증거)는 도입 단계 뒤 중반 이후에 나온다. 제출 방식 안내(mailto 여부 등)는 확인 불가.

### 5위 S6
- 장점: 기능 → 도입 → 성과 → 폼의 흐름이 단정하고, 다크 섹션 안에 수치와 인용을 함께 묶어 증거를 한 번에 보여준다("현장의 정지 시간이 줄어듭니다").
- 결함: S4와 같은 칩+카드 중복 도입 단계가 있고, 폼 영역에 응답 시한·안심 문구가 없어 전환 보조 장치가 가장 약함. 증거가 후반부에 있음.

### 6위 S1
- 장점: 가장 짧고 단순한 구조(히어로 → 기능 → 수치 → 4단계 → 인용 → CTA)로 모바일에서도 가볍고, 수치 출처("도입 6개월 후 평균, 12개 공장 기준")를 명시.
- 결함: 페이지 끝 CTA가 폼 없이 '데모 신청하기' 버튼 하나뿐이라 클릭 후 경로가 확인 불가이고, 이름·회사 등 B2B 리드 정보를 받는 구조가 보이지 않음. 헤더 로고가 텍스트뿐이라 브랜드 신뢰감이 약함. 폼 부재가 구매 담당자 관점에서 가장 큰 약점.

## 3) 시안 간 비교
### 서로 구분되지 않는 점
1. 히어로: 헤드라인·본문·CTA 두 개·대시보드 목업 구성이 사실상 동일(줄바꿈, 색조만 다름).
2. 콘텐츠: 동일한 3기능·4단계·3수치·1인용 문구, 같은 회색 설비 일러스트. 모든 시안이 고객사 로고, 보안/인증, 가격, 복수 사례를 갖지 않음.
3. 시각 언어: 파란 계열 CTA, 흰/연회색/네이비 섹션 교차, 둥근 카드 스타일이 비슷해 브랜드 개성이 구분되지 않음. 두 번째 CTA '도입 사례 보기'는 모두 도착 지점 확인 불가.

### 정말 다른 점
1. 신뢰 증거의 위치: S3(히어로 바로 아래), S2(두 번째 섹션)에서 S1/S4/S5/S6(중반 이후)까지 편차가 큼.
2. 최종 전환 장치: 폼 없음(S1) vs 인라인 폼(S2~S6). S2는 응답 시한, S3/S4는 읽기 전용·기간 안심 문구, S3는 mailto 고지, S6는 보조 문구 없음으로 다름.
3. 헤드라인 구조: S2는 두 번째 섹션을 결과(4.2일 전)로 재진술, S4/S5는 혜택형 문장, 나머지는 기능 나열. 도입 단계 표시도 단선 타임라인(S1/S2/S3/S5) vs 칩+카드 중복(S4/S6) 차이가 있음.
