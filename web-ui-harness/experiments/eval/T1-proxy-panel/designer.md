# 알파로그 랜딩 시안 S1~S6 디자이너 평가

## 1) 5초 테스트 (firstfold-desktop.png만 본 상태)
공통: 6개 모두 헤드라인 "설비 로그에서 고장의 징후를 먼저 찾아냅니다", 서브카피, 버튼 2개(데모 신청하기/도입 사례 보기), 우측 대시보드 목업(설비 위험도 막대, 추이 선그래프, 원인 후보)이 거의 동일. 그래서 Q1~Q3 답은 6개가 같고, 차이는 Q4와 첫인상 정도.

| | Q1 무엇 | Q2 누구 | Q3 다음 행동 | Q4 신뢰 (구체 증거) |
|---|---|---|---|---|
| S1 | 설비 로그로 고장 징후를 미리 찾는 예지 정비 SW | 공장 설비/정비 담당 (명시 없음, 목업 용어로 추정) | 파란 "데모 신청하기" 클릭 | 첫 화면엔 수치·고객 증거 없음. 목업의 설비명(사출기 07 등)뿐. 약함 |
| S2 | 동일 | 동일 | 데모 신청하기 | 첫 화면 증거 없음, 목업 외에는 없음. 아래 어두운 섹션이 시작되는 것만 보임 |
| S3 | 동일 | 동일 | 데모 신청하기 | 목업 캡션 "설비별 위험도와 추이를 한 화면에서 확인"뿐, 수치 없음. 아래 공장 일러스트가 보이나 증거는 아님 |
| S4 | 동일(+"예지 정비 소프트웨어" 아이브로) | 동일 | 데모 신청하기 | 첫 화면 증거 없음 |
| S5 | 동일 | 동일 | 데모 신청하기 | 첫 화면 증거 없음 |
| S6 | 동일(+아이브로) | 동일 | 데모 신청하기 | 첫 화면 증거 없음 |

Q4 결론: 6개 모두 첫 화면에서 구체 신뢰 증거(고객 로고, 수치, 인증)는 확인 불가. 목업 화면이 유일한 "실제 제품" 단서.

## 2) 순위 (모바일·전체 페이지 확인 후)
1위 S2 / 2위 S5 / 3위 S3 / 4위 S1 / 5위 S6 / 6위 S4

### 1위 S2
- 장점: 3줄 큰 헤드라인과 CTA 위계가 가장 선명. 히어로 직후 어두운 섹션 "정지가 일어나기 평균 4.2일 전에 알려드립니다" + 타임라인 도식으로 수치를 이야기로 풀어 템플릿 느낌이 덜함. 하단에 실제 입력 폼(이름/회사명/이메일/연락처/문의)이 있어 전환 동선이 완결.
- 결함: 타임라인 도식(설비 정지 점 하나와 가로선)이 텅 비어 있고 라벨이 작아 메시지에 비해 여백만 큼. 카드 없이 리스트로 처리한 "알리는 데서 끝나지 않고" 섹션은 좌우 간격이 넓어 읽는 눈이 멀리 이동.

### 2위 S5
- 장점: 성과 섹션에서 "38%"를 아주 크게, 나머지 두 수치는 행 리스트로 대비를 줘 위계가 분명. 하단 풀블리드 파란 폼 섹션 + 흰 카드로 마감이 강함.
- 결함: 히어로 아래 3줄 리스트 → 공장 일러스트 밴드(회색 블록) → 어두운 단계 섹션으로 이어지는데, 일러스트 밴드가 전폭이고 블록이 투박해 임시 이미지처럼 보임. 인용문 카드(우측)는 회색 박스 안에 작게 놓여 힘이 약함.

### 3위 S3
- 장점: 네이비+주황 포인트로 다른 시안보다 색 개성이 있고, 기능 목록에 선 아이콘(파형/캘린더/노드)과 가는 구분선을 써서 카드 남발이 없음. 목업 하단 캡션이 제품명을 연결.
- 결함: 히어로 바로 아래 전폭 회색 공장 일러스트(블록 4개, 컨베이어, 점)가 매우 커서 플레이스홀더처럼 보이고 첫 화면 하단을 점령. 모바일에서는 캡션의 "알파로그 프리딕트"가 줄바꿈되어 어색(S3 모바일 하단).
- 참고: 주황 포인트가 폼 체크 마커·4단계 원에만 쓰여 일관성은 있으나 CTA 파랑/네이비와 역할 구분은 확인 불가.

### 4위 S1
- 장점: 가장 절제되고 정돈된 구성. 4단계는 상단 파란 선 + 숫자 표기로 간결하고, 카드는 3개뿐. 섹션 간 여백이 안정적.
- 결함: 상단 로고가 일반 텍스트 "알파로그"라 브랜드 존재감이 약하고, 마지막 CTA 블록이 폼 없이 흰 버튼 하나뿐이라 전환이 한 단계 더 필요. 히어로 목업 프레임 위쪽이 비어 있어(창 바가 프레임 중간에 걸림) 어색(S1 첫 화면 우측).

### 5위 S6
- 장점: 성과 수치(38%/4.2일/3주)와 인용문·공장 일러스트를 하나의 어두운 섹션에 묶어 페이지가 S4보다 짧고 응집됨(S6 중하단).
- 결함: "도입 흐름"에서 박스형 스텝 막대와 그 아래 번호 카드 4개가 같은 내용을 반복(S6 중반). 히어로 목업 프레임 상단이 비어 창 바가 중간에 걸려 보임(S6 첫 화면 우측). 카드3개+스텝+다크 수치+폼의 전형적 템플릿 순서.

### 6위 S4
- 장점: 아이브로 라벨(핵심 기능/도입 흐름/도입 성과/고객 이야기/데모 신청)로 섹션 구분이 일관되고 폼이 연한 파란 배경 섹션 위 카드로 정돈됨.
- 결함: S6와 같은 스텝 중복(S4 중반)에 더해, 인용 섹션이 흰 카드 안에 일러스트를 작게 넣어 떠 보이고 좌우 균형이 약함(S4 하단). 히어로 목업 상단 공백도 동일. 구조상 가장 길고 가장 평균적인 SaaS 템플릿.

## 3) 시안 간 비교
### 서로 구분되지 않는 점
1. 히어로: 동일 헤드라인/서브카피/버튼 문구, 우측에 동일한 대시보드 목업. 어느 시안인지 가려도 거의 같음.
2. 하단 구조: 기능 3개 → 4단계 → 수치(38%, 4.2일, 3주) → 인용(김지훈) → 데모 신청 → 다크 푸터. 문구까지 거의 같음.
3. 시각 언어: 둥근 사각 버튼, 회색 블루 배경, 파랑 CTA, 어두운 네이비 구간, 같은 회색 블록 공장 일러스트. 전체적으로 평균적 SaaS 템플릿.

### 정말 다른 점
1. 정보 형태: S2는 수치를 타임라인 도식과 문장형 헤드라인으로 풀었고, 나머지는 큰 숫자 3개 나열(S5는 38% 하나만 크게 강조).
2. 색 체계: S3는 네이비+주황, S2/S5는 비비드 파랑 계열, S1·S4·S6은 파랑 일관(S1은 더 어두운 파랑, S6 CTA는 밝은 파랑).
3. 전환 구조: S2·S3·S4·S5·S6은 입력 폼, S1은 폼 없이 버튼 CTA만. 기능 표시도 카드(S1,S4,S6) vs 선 리스트(S2,S5) vs 아이콘 리스트(S3)로 갈림.
