# 구매 담당자 관점 평가 (S1~S6)

## 1) 첫 화면 5초 인상 (Q1 무엇 / Q2 누구 / Q3 다음 행동 / Q4 신뢰)
공통: 알파로그라는 회사의 "알파로그 프리딕트"는 공장 설비 로그/센서 데이터를 분석해 고장 전에 점검 시점을 알려주는 예지 정비 소프트웨어. 공장 설비 담당자용. 다음 행동은 "데모 신청하기" 클릭.
- S1: Q1 설비 고장 징후 예측 소프트웨어. Q2 공장 설비/정비 담당자. Q3 데모 신청하기. Q4 화면 예시가 구체적이라 어느 정도 믿음, 다만 로고가 글자뿐이고 첫 화면에 고객사나 숫자가 없어 "아직 판단 보류".
- S2: Q1 동일. Q2 동일. Q3 데모 신청. Q4 큰 제목과 실제 화면 같은 대시보드 때문에 제품이 실재하는 느낌이나 첫 화면 아래는 검은 띠뿐이라 근거는 못 봄.
- S3: Q1 동일. Q2 동일. Q3 데모 신청. Q4 화면 아래에 "설비별 위험도와 추이를 한 화면에서 확인"이라는 설명이 붙어 제품이 이해되고 차분한 남색이라 믿음이 감. 단 아래 회색 설비 그림은 의미를 모르겠음.
- S4: Q1~Q3 동일. Q4 "예지 정비 소프트웨어"라는 분야 표시가 있어 이해는 빠르나 믿을 근거(고객/숫자)는 첫 화면에 없음.
- S5: Q1~Q3 동일. Q4 깔끔하고 정돈되어 호감이나 근거는 아직 없음. 메뉴가 로고 옆에 붙어 있어 살짝 다른 느낌.
- S6: S4와 거의 같음. 분야 표시와 제목이 한눈에 들어옴. Q4 근거는 아직 없음.

## 2) 전체 페이지 후 순위 (데모 신청 의향 + 신뢰)
1. S2 - 제목 바로 아래 "정지 평균 4.2일 전에 알려드립니다"가 크게 나오고 숫자 3개, 4단계 도입 과정, 고객 한마디, 그리고 이름/회사/이메일 신청 양식이 한 페이지 안에 다 있어 바로 신청할 수 있음. 영업일 1일 이내 연락한다는 약속도 안심됨.
2. S3 - 첫 화면 바로 아래에 38%, 4.2일, 3주 숫자가 보이고 "설비 로그는 읽기 전용으로만 연결"이라는 안심 문구가 신청 양식 옆에 있음. 아이콘이 있는 기능 설명도 이해하기 쉬움.
3. S5 - 38%가 아주 크게 보여 인상적이고, 파란 바탕의 신청 양식이 눈에 확 띔. 설비 종류 예시(사출기, 프레스, 컨베이어)가 있어 내 설비 얘기를 해도 되겠다는 느낌.
4. S4 - 기능, 4단계, 숫자, 고객 한마디, 신청 양식이 순서대로 다 있어 빠진 것은 없으나 전체가 무난해서 특별히 끌리지 않음. 가격도 양식 옆에서 안내한다고 해서 도움됨.
5. S6 - S4와 구성이 거의 같고 숫자가 어두운 바탕에 들어가 있으나 4단계 설명이 두 번 반복되어 길게 느껴짐.
6. S1 - 숫자와 고객 한마디는 있지만 페이지 끝에 신청 양식이 없고 버튼만 있어, 눌러야 무엇이 나오는지 모름. 연락처도 맨 아래 작게만 있음.

(참고: 모든 시안의 전화번호가 02-000-0000, 이메일이 example로 보여 실제 회사 연락처처럼 안 보이고, 고객 이름 회사가 "가상정밀"이라 진짜 고객 같지 않음. 숫자 근거도 "12개 공장 기준" 한 줄뿐이라 어느 공장인지 알 수 없음. 이 점은 6개 모두 신뢰를 깎음.)

## 3) 읽기 힘들거나 헷갈린 곳
- S1, S4, S6 첫 화면: 대시보드 그림 위아래에 빈 흰 칸이 넓어 그림이 둥둥 떠 보임. 그림 속 글씨(원인 후보 등)는 너무 작아 읽기 힘듦.
- S3 첫 화면 하단 및 중간: 회색 네모들(설비 그림)이 크게 나와 무엇인지 모르겠고 내용 없는 빈 칸처럼 보임. 같은 그림이 S1(고객 이야기 옆), S2(고객 한마디 옆), S4, S5, S6 아래쪽에도 나오는데 역시 의미 파악 어려움. S6는 기능 설명과 도입 과정 사이에 단독으로 크게 있어 가장 헷갈림.
- S2 두 번째 구간(검은 바탕): "설비 정지 / 알파로그가 없었다면"이라는 선 위의 점 그림이 무슨 뜻인지 한눈에 안 읽힘. 같은 바탕의 작은 회색 글씨도 읽기 힘듦.
- S5 중간: 4단계 도입이 위 박스줄과 아래 카드로 두 번 나옴. S4도 같은 이유로 헷갈림(S4: 단계가 선과 박스, 카드 두 번 반복).
- S6: "38%"만 아주 크고 나머지 두 숫자는 작은 글씨라 균형이 맞지 않아 세 번째 숫자를 놓치기 쉬움.
- S3 신청 양식 아래: "제출하면 메일 앱이 열립니다"라는 문구 때문에 신청이 바로 안 되는 것처럼 보임(S5도 비슷).
- S1 마지막 푸른 구간: 흰 버튼 하나만 있어 양식이 없어 아쉬움.
