# 디자인 결정
- Persuade 모드 단일 랜딩. 섹션 제목은 출력 금지 규칙에 따라 보이는 제목 없이 aria-label로만 구분, 플랜명(표 머리글)은 열 제목으로 표시, "항목" 모서리 셀은 sr-only.
- 팔레트: 차가운 종이색 #F3F5FA, 잉크 #141B34, 코발트 #2A44F0(단일 포인트), 다크 모드 대응. 크림/테라코타 회피.
- 서명 요소: 계단형 로고와, 데스크톱에서 계단처럼 어긋나게 배치한 기능 카드 보드(어두운 밴드). 아이콘/번호/아이브로 없음.
- 요금표: >=960px는 실제 table, 그 아래는 플랜별 카드(dl)로 재구성해 가로 스크롤 없음.
- 내비: 모바일은 햄버거 대신(문구 추가 방지) 링크를 줄바꿈 표시, 1100px+에서 한 줄.
- 폼: "(필수)"는 "필수" 표기+required, 팀 규모 기본 옵션은 "선택". 카드 제목/설명의 " — "는 구분 위치로만 사용하고 출력 안 함.
- Pretendard 4굵기 로컬 @font-face, 외부 리소스 없음. 다크모드 CTA 대비는 detect 결과로 수정.
