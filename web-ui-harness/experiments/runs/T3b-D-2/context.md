1. 모드는 Read: 본문 가독성이 최우선, 장식·모션 없음. 문구는 content.md 그대로(대괄호 표기와 필드명만 제외).
2. 폰트는 Pretendard 단일 패밀리(Regular/Medium/SemiBold/Bold, 로컬 woff2), 굵기와 크기 대비로만 위계를 만듦.
3. 본문 19px(모바일 17px)/행간 1.85, 폭 약 34em, word-break: keep-all로 한글 어절 보존, 문단 간격으로만 리듬.
4. 색: 차가운 흰 종이색 + 짙은 청회색 잉크 + 단일 딥 틸 포인트(소제목 표식, 선택색, 포커스). 다크 모드 지원.
5. 분류 문구는 아이브로(제목 위 라벨)를 피해 부제 아래 메타 줄에 작성자·날짜와 함께 배치.
6. 소제목은 위 여백을 크게, 아래는 작게 두어 문단과 묶고, 번호·카드·박스 없이 한 단 구성.
7. 제목은 text-wrap: balance, 데스크톱에서 큰 크기, 좌측 정렬. 가로 스크롤 없음, 320px까지 검증.
