# 디자인 결정 (Read 모드, PRODUCT.md 기준)
- 색: 차가운 중성 바탕(#f3f5f8) + 남청 포인트(#1f3f8f), 야간 센터의 서늘한 조명. 크림/세리프 기본값 회피. 다크 모드는 prefers-color-scheme 대응.
- 타입: Pretendard 단일 패밀리(400/500/600/700). 본문 18~19px, 행간 1.9, word-break: keep-all, 한 줄 약 30~40자.
- 제목은 크게(최대 3.75rem, 자간 -0.035em), 부제는 회색 톤으로 위계 분리. eyebrow 없이 분류는 바이라인 줄에 포함.
- 레이아웃: 데스크톱은 소제목을 왼쪽 열(sticky)에 두고 본문을 오른쪽 좁은 열에 배치해 길찾기를 돕고, 모바일은 단일 열.
- 첫 문단만 약간 크고 굵게(리드). 문단 구분은 간격만 사용, 소제목 위에 짧은 포인트 선.
- 모션 없음, 선택 색/포커스 링을 팔레트로 지정. 문구는 content.md 그대로(대괄호·필드명 제외).
