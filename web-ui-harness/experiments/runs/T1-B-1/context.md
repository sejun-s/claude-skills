1. 모드 Persuade. 대상은 설비보전 책임자라 장식보다 근거(수치, 절차, 인용)를 앞세움.
2. 팔레트: 종이 같은 차가운 회색 #f3f4f6, 잉크 #151a22, 신호 블루 #2350c4(에셋과 일치), 경보색 #c8403b은 위험 표시에만 사용.
3. 타입: Pretendard 단일 패밀리, 400/500/600/700. 헤드라인은 크고 타이트(-0.03em), 본문 17px, 줄 길이 제한.
4. 기억할 한 가지: 수치 섹션의 "감지 4.2일 → 정지" 타임라인 SVG. 히어로 메트릭 템플릿 대신 제품의 핵심 가치(먼저 안다)를 시간축으로 시각화.
5. 기능 3개는 카드가 아니라 구분선 있는 행 레이아웃, 도입 4단계는 실제 순서라 번호 사용, 에셋의 flow-diagram은 모바일 가독성 때문에 HTML 단계 목록으로 대체.
6. 어두운 잉크 구간은 수치 섹션 하나만 두어 리듬을 만들고 나머지는 밝게 유지.
7. 모션은 히어로 로드 시 타임라인 마커 1회만, prefers-reduced-motion 존중.
8. 데모 신청 폼은 프런트엔드 전용(전송 없이 확인 메시지)이며 실제 연동은 필요.
