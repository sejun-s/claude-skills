- 모드 Persuade. 방향: 차분한 엔지니어링 톤, 쿨 그레이 종이색 + 짙은 네이비 + 에셋과 같은 블루(#2b5fd9) 단일 강조. 폰트는 Pretendard 한 가족(굵기 400-700).
- 히어로: 좌측 정렬 헤드라인 + 대시보드 화면을 실제로 보여줌. 유일한 모션은 화면이 올라오는 1회 진입(reduced-motion 존중).
- 수치는 히어로 메트릭 템플릿 대신 어두운 띠에서 근거 문구와 함께 한 줄로 제시. 기능 3개는 카드 대신 구분선 목록, 단계는 실제 순서라 번호 사용.
- 흐름 다이어그램 SVG는 모바일에서 글자가 작아져 숨기고 4단계 목록으로 대체. 데모 신청은 페이지 하단 인라인 폼(백엔드 없음, 클라이언트 접수 확인만).
- 제목 구 보존(ko-heading-wrap): "설비 로그에서/고장의 징후를/멈추기 전에/예지 정비/평균 3주/데모를 신청하세요"를 nb로 묶음. heading-lines 결과: 320~1440 모든 폭에서 쪼개진 구 없음.
