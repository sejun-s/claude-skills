- 세계관: 한국 업무 서식의 괘선·라벨 셀. 표/카드/폼이 모두 같은 1px 괘선 격자 문법을 공유.
- 색: 코발트 #2340E0 밴드(요금제가 첫 화면), 네이비 잉크 #101B3D, 차가운 종이 #F4F6FA, 라벨 틴트 #E6EBF7, 형광펜 노랑 #FFD23F은 행동 버튼에만.
- 서체: Pretendard 단일(400/500/600/700), 요금 행만 크게(탭 숫자), keep-all 줄바꿈.
- 문구 불변: 섹션 제목은 화면에 쓰지 않고 aria-label만 사용. 메뉴 버튼도 aria-label 아이콘.
- 요금표: 720px 이상 실제 표, 미만은 항목별 블록(플랜명은 data-plan으로 표시)으로 전환해 가로 스크롤 없음.
- 기능 카드: 아이콘/번호 없이 공유 괘선 그리드 1/2/4열, 긴 제목 text-wrap:balance.
- 폼: 라벨 셀+입력 셀 서식, 팀 규모는 라디오 세그먼트(빈 옵션 문구 방지), 포커스·선택·캐럿 색 테마화.
- 내비: 1180px 이상 가로 나열, 미만은 햄버거 패널. CTA는 항상 노출.
- 검증: 320/768/1440 가로 오버플로 0, detector 경고 2건(cramped-padding)은 래퍼/표 카드의 의도된 구조라 오탐으로 판단.
