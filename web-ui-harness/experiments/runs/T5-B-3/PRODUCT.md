# PRODUCT

## Product
스텝보드: 가상의 팀 업무 관리 SaaS (보드, 자동화, 승인 워크플로, 감사 로그). 한국어 UI.

## Audience
팀 리더, 운영/IT 담당자, 보안·규정 준수 검토자. 요금제를 비교하고 도입 문의를 보내려는 B2B 구매 검토자. 데스크톱과 모바일 모두 사용.

## Purpose (mode: Persuade)
기능을 이해하고, 요금제를 비교한 뒤, 무료로 시작하거나 문의를 보내게 한다. 요금제 비교표의 정확한 읽힘이 핵심.

## Tone
차분하고 정확하며 신뢰감 있는 업무 도구. 과장 없음. 승인 단계(step)라는 제품 개념에서 시각 언어를 가져온다.

## Constraints
content.md 문구 그대로, 추가/변경 금지. Pretendard 로컬 폰트. 외부 리소스 금지. 320-1440px 대응.
