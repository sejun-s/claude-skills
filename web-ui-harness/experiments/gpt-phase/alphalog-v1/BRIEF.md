# E-GPT practical application v1 — frozen before final verification

2026-10-02. User request: usable web UI and a complete reusable skill; reuse open source; avoid expanding research for its own sake. This phase follows that updated scope, preserving the earlier A/B/C/D experiments.

Surface: fictional Alphalog predictive-maintenance landing page, reused from T1's product facts. Audience: manufacturing maintenance/production teams. Main purpose: understand the service through a real interactive product example, then prepare a demo inquiry. New slogan, copy, layout, palette and product sample data are authored for this example and are not the frozen T1 benchmark content. There is no controlled A/B comparison.

Visual direction: light paper-like canvas, evergreen ink, selective lime accent, Korean sans typography, restrained editorial spacing, a full-width working product canvas. Responsive behavior changes the product list from vertical to horizontal and hides the noninteractive sidebar on phones. Native accordion and forms, real keyboard tabs, no animation required for visibility.

Implementation scope: semantic static HTML/CSS/JS, local pinned Pretendard fonts, no frontend build step, no authentication/database/submission backend. All product example data, performance figures and customer quotes remain visibly fictional. The form produces a local request text with clipboard copy and cannot send it.

Reuse: Impeccable design guidance adapted inside `web-ui-craft`; no detector or binary installed. Icons, brand mark and product SVG chart are authored geometric UI rather than copied visual illustrations. Existing measurements and logs are retained.

Acceptance: render at 320/375/768/1440; check actual loaded fonts and resource/console errors; verify document overflow also at 1024/1920 after interactions; exercise machine/period selection, keyboard tabs, mobile navigation, disclosures, required/email validation, inert prepared text, clipboard and information page. Contrast checks cover visible HTML text with computed solid backgrounds; SVG/focus/hover remain manual review. No claim of aesthetic effect until user judgment.
