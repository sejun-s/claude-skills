# ko-heading-wrap

> v0.2 (미검증): v0.1 실험에서 좁은 폭 해제 규칙과 지나치게 긴 묶음이 반복해서 실패를 만들어 구현 2번을 고쳤다. 효과 판정은 v0.1 결과(failures/log.md)이며 v0.2는 재측정 전이다.

`word-break: keep-all`은 어절(띄어쓰기 단위)만 지킨다. "신규 / 가입 혜택을", "가입하기 / 전에", "배송 / 추적이"처럼 **구**가 쪼개지는 것은 막지 못하고, `text-wrap: balance`도 보장하지 못한다. 폭이 바뀌면 끊기는 자리도 바뀐다.

## DG-KO-001 — 제목 구 단위 보존
- **조건:** 한국어 제목이 어떤 폭에서든 2줄 이상이 된다.
- **결정:** 한 덩어리로 읽혀야 하는 구는 줄 경계에서 쪼개지지 않게 한다.
  한 덩어리로 보는 것: 수식어 + 핵심어("신규 가입 혜택", "빠른 정산"), 고정 복합어("배송 추적", "결제 수수료"), 시간·조건 구("가입하기 전에"), 숫자 + 단위("24시간", "5분").
  덩어리로 보지 않는 것: 서로 다른 절, 조사 뒤의 새 어절 묶음(무엇이 한 덩어리인지 애매하면 묶지 않는다).
- **이유:** 줄바꿈이 읽기 단위를 갈라 제목 의미가 두 줄로 흩어진다. 제목은 한눈에 읽는 요소라 줄바꿈이 곧 문장 구조다.
- **구현:**
  1. 묶을 구를 `<span class="nb">…</span>`로 감싸고 `.nb { white-space: nowrap }`.
  2. **좁은 폭에서만 nowrap을 푸는 규칙을 넣지 않는다**(풀면 그 폭에서 바로 쪼개진다). 대신 구 하나는 가장 좁은 폭(320px)에서도 컨테이너 안에 들어가야 한다. 안 들어가면 묶음을 더 짧게 나누거나 제목 `font-size`를 `clamp()`로 줄인다. 구두점(—, 쉼표)은 앞 구에 붙이지 않는다. **가로 넘침을 만들면 실패.**
  3. 덩어리 길이가 제목의 절반을 넘으면 너무 크게 묶은 것이다 — 줄인다.
  4. `text-wrap: balance`는 보조 수단으로 유지한다(대체 아님).
- **안티패턴:** 제목 전체를 nowrap으로 묶기, 줄바꿈을 `<br>`로 고정하기(폭이 바뀌면 깨짐), 모든 어절 사이를 `&nbsp;`로 잇기, 폭 하나만 보고 판단하기.
- **예외:** 한 줄로 끝나는 제목, 장문 본문 단락(구 단위 보존은 제목류에만).

## 절차
1. 제목 텍스트를 확정한 뒤 위 기준으로 묶을 구를 정한다(제목당 보통 1~2개).
2. 위 구현대로 마크업한다.
3. 폭별 줄바꿈을 확인한다(경로는 이 스킬 폴더 기준):
   ```
   node scripts/heading-lines.mjs <index.html> --keep "신규 가입 혜택,가입하기 전에" --widths 320,375,768,1024,1440
   ```
   `--keep` 없이 실행하면 모든 제목의 폭별 줄 구성과 마지막 줄 고아만 보여 준다(구 쪼개짐은 검사하지 않는다는 안내가 나온다). **묶은 구를 전부 `--keep`에 넣어야 쪼개짐을 검사한다.** 줄 구성도 눈으로 읽고, 묶지 않은 구가 어색하게 끊기면 그 구도 묶는다.
   쪼개진 구나 가로 넘침이 나오면 2번으로 돌아가 고친다. **수정 후에는 반드시 다시 실행해 결과를 확인한다.** 최대 3회.
4. 실행 결과(어떤 구를 묶었고 마지막 출력이 어땠는지)를 작업 폴더의 `context.md`에 한 줄로 남긴다.

## 이 스킬이 하지 않는 것
제목 문구 변경, 본문 줄바꿈, 폰트 선택, 레이아웃 판단. 줄바꿈 때문에 문구를 고치지 않는다.
